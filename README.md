# MySpace Dashboard V5

Tableau de bord personnel en HTML, CSS et JavaScript, prêt pour GitHub Pages.

## Fonctionnalités
- Gestion des tâches : création, modification, suppression, catégories, priorités, échéances et statut.
- Recherche et filtres des tâches.
- Projets avec progression de 0 à 100 %.
- Calendrier mensuel avec tâches par journée.
- Notes modifiables et supprimables.
- Statistiques par catégorie et priorité.
- Thème clair/sombre et liens rapides personnalisables.
- Export/import JSON.
- Données conservées localement dans le navigateur via `localStorage`.
- Interface responsive pour ordinateur, tablette et mobile.

## Installation GitHub Pages
1. Décompresse le ZIP.
2. Ajoute `index.html`, `style.css`, `app.js` et `README.md` à la racine de ton dépôt GitHub.
3. Fais un commit.
4. Dans **Settings → Pages**, sélectionne **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis enregistre.
5. Ouvre l'adresse GitHub Pages indiquée par GitHub.

## Sauvegarde
Les données restent dans le navigateur utilisé et ne se synchronisent pas automatiquement entre appareils. Va dans **Paramètres → Exporter mes données** pour créer une sauvegarde JSON.

Le site ne nécessite aucun serveur ou framework. Google Fonts est utilisé pour la police ; le reste fonctionne en statique.
